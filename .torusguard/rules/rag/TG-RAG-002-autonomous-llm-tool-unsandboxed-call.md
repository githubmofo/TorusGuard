# TG-RAG-002: Autonomous LLM Tool Unsandboxed Call

## Severity
Critical. Executing system shell commands, raw SQL, or filesystem modifications based directly on model tool call outputs without schema validation or sandboxing allows remote code execution (RCE).

## Applies To
- LLM Function Calling, Agent Tool Calling, ReAct loops, Model Context Protocol (MCP) servers
- Python, Node.js, Go

## Why It Matters
When an AI agent calls external tools (e.g. `execute_code`, `query_database`, `run_bash`), the arguments originate from stochastic model generation. If the model was prompted or tricked via prompt injection to emit `rm -rf /` or `DROP TABLE users;`, executing those arguments without strict allowlists, parameterization, or sandboxing destroys data or compromises the server.

## What TorusGuard Looks For
1. Passing tool call arguments directly to `os.system`, `subprocess.run(..., shell=True)`, or `child_process.exec`.
2. Evaluating raw SQL emitted by LLM tool calls without parameterization.
3. Lack of human-in-the-loop confirmation on destructive tool invocations.

## Unsafe Example
```python
# UNSAFE: Unsandboxed execution of model tool call
def handle_tool_call(tool_call):
    if tool_call.function.name == "run_command":
        args = json.loads(tool_call.function.arguments)
        # Directly executes arbitrary shell command generated by LLM!
        return subprocess.check_output(args["cmd"], shell=True)
```

## Safe Example
```python
# SAFE: Strict schema validation, command allowlisting, and no shell=True
ALLOWED_COMMANDS = {"git status", "git diff", "npm test"}

def handle_tool_call(tool_call):
    if tool_call.function.name == "run_command":
        args = json.loads(tool_call.function.arguments)
        cmd = args.get("cmd", "").strip()
        
        if cmd not in ALLOWED_COMMANDS:
            raise PermissionError(f"Command not permitted: {cmd}")
            
        return subprocess.check_output(cmd.split(), shell=False)
```

## Remediation
1. Enforce strict Pydantic/Zod schemas on all tool arguments.
2. Ban `shell=True` when invoking sub-processes from AI tool calls.
3. Require explicit human confirmation (Human Gate) for state-altering, file-writing, or network operations.
