3. NEW SECURITY RULES IMPLEMENTED
--------------------------------------------------------------------------------
Seven canonical security rules were developed, tested, and cataloged into rules/:

  * TG-AGENT-001 (Critical): AI System Prompt Injection Boundary Defenses.
    Enforces user input isolation into role: "user" and prohibits unescaped template concatenation.
  * TG-AGENT-002 (Critical): Unsandboxed Shell Tool Execution Guard.
    Requires strict allowlisting and container isolation before agents run shell tools.
  * TG-AGENT-003 (High): Overly Broad MCP Tool Scoping.
    Enforces least-privilege tool exposition on Model Context Protocol servers.
  * TG-AGENT-004 (High): Cross-Session Vector Memory Data Leakage.
    Mandates tenant isolation and encryption on persistent embeddings and semantic memories.
  * TG-EDGE-001 (High): Edge Runtime Isolate Memory Leak Prevention.
    Detects global mutable state in Cloudflare Workers and V8 edge isolates.
  * TG-EDGE-003 (High): AWS Lambda Cold-Start Credentials & Timeout Protection.
    Guards against stale in-memory secrets and unhandled handler timeouts.
  * TG-SUPPLY-006 (High): BuildKit Secret Mounts in Container Builds.
    Enforces Docker '--mount=type=secret' instead of leaking keys via ARG or ENV.
