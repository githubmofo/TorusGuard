# TorusGuard Example Applications

Documentation-rich reference examples for TorusGuard audits. These are **not production applications**.

| Example | Purpose |
|---------|---------|
| [vulnerable-react-express/](vulnerable-react-express/) | Intentionally insecure patterns mapped to rule IDs — **never deploy** |
| [hardened-react-express/](hardened-react-express/) | Corrected patterns for the same scenarios |

Compare `vulnerabilities.md` and `fixes.md` side by side when learning or testing `/TorusGuard audit` and `/TorusGuard harden`.

All secrets in examples are fake placeholders labeled non-functional.
