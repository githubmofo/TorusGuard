## Wave 1: Universal Polyglot Stack Detection

Modern software architectures are increasingly polyglot, combining Go microservices, Java enterprise backends, Rust systems components, and TypeScript frontends. TorusGuard v1.3.0 profiles any workspace across three detection layers:

### Detection Layers
1. **Primary Manifest Catalog:** Inspects root and nested manifests (`go.mod`, `Cargo.toml`, `pom.xml`, `build.gradle`, `*.csproj`, `composer.json`, `Gemfile`, `mix.exs`, `pubspec.yaml`, `CMakeLists.txt`, `package.json`, `pyproject.toml`).
2. **Framework & ORM Heuristics:** Scans manifest contents for framework dependencies (Spring, Gin, Fiber, Actix, Axum, ASP.NET Core, Laravel, Rails, Phoenix, Flutter, Django, FastAPI, Next.js) and database mappers (GORM, Diesel, SQLx, Hibernate, Entity Framework Core, Eloquent, ActiveRecord, Ecto, SQLAlchemy, Prisma, Drizzle).
3. **Extension Census Fallback:** When manifest files are missing or placed non-standardly, the engine surveys source code extensions (`.go`, `.rs`, `.java`, `.cs`, `.php`, `.rb`, `.kt`, `.ex`, `.dart`, `.cpp`, `.scala`, `.swift`) to determine the dominant runtime environment.

## Wave 2: Polyglot Content-Aware Diff Guard

TorusGuard's Diff Guard (`diff_guard.py`) now intercepts dangerous security regressions across polyglot unified diffs before code merges.

### Multi-Language Bypass Patterns (`TG-DIFF-001`)
- **Go:** Intercepts disabled TLS certificate validation (`InsecureSkipVerify: true`, `tls.Config{InsecureSkipVerify: true}`).
- **Java:** Blocks disabled Spring Security CSRF (`csrf().disable()`) and unrestricted route access (`permitAll()`).
- **C#:** Intercepts unauthenticated endpoint attributes (`[AllowAnonymous]`) and permissive SSL callbacks (`ServerCertificateCustomValidationCallback = .*true`).
- **PHP:** Blocks disabled cURL peer verification (`CURLOPT_SSL_VERIFYPEER => false`, `verify => false`).
- **Rust:** Flags unvetted `unsafe {` blocks introduced in security-critical routines.

### Multi-ORM Tenant Boundary Stripping (`TG-DIFF-003`)
Blocks pull requests that remove multi-tenant isolation filters from database queries across:
- **GORM:** Removal of `.Where("tenant_id = ?")` or `.Where("org_id = ?")`.
- **LINQ / EF Core:** Removal of `.Where(x => x.TenantId == ...)` or `.Where(x => x.OrgId == ...)`.
- **Prisma:** Removal of `where: { tenantId: ... }` or `where: { orgId: ... }`.

## Wave 6: Dual-Strategy Governance Architecture (Terminal CLI & AI Chat Workflows)

To ensure seamless security governance for developers in Cursor, standard VS Code, or CI/CD runners where AI chat slash commands are not available, v1.3.0 establishes full CLI governance parity:

1. **Dedicated CLI Commands Suite (`bin/torusguard.js`):**
   - `npx torusguard harden`: Formulates surgical candidate patch plans adhering strictly to the Ponytail Protocol ($\le 35$ additions, $\le 25$ deletions). Emits candidate bundles under `.torusguard/runs/<run_id>/bundles/<bundle_id>/` with `patch.diff`, `minimal_patch_plan.md`, `metadata.json`, and run-level `remediation.md`.
   - `npx torusguard apply`: Interactive terminal Human Gate authorization prompt (`[y/N/all/quit]`) with syntax-highlighted diffs, non-interactive `--yes` / `-y` support, automatic pre-apply `.bak` snapshots in `.torusguard/snapshots/<run_id>/`, and automatic distillation of verified fixes into Golden Fix Recipes in `.torusguard/memory/patterns.json`.
   - `npx torusguard rollback`: Instant one-command rollback restoring all `.bak` files from `.torusguard/snapshots/<run_id>/` back to disk without data loss.
   - `npx torusguard recheck`: Targeted differential AST scan over modified file scopes evaluating `Confirmed Fixed` vs `Regressed` state machine and appending `fix_verified` events.
   - `npx torusguard recipes`: Interactive explorer for distilled Golden Fix Recipes with Ponytail metrics, rule IDs, and unified diff previews.
2. **Visual HTML Report Dual-Strategy Flowchart (`html_reporter.py`):**
   - Updated 7-stage interactive pipeline flow to show dual prompts for both CLI and chat (`audit · /audit`, `harden · /harden`, `apply · .bak`, `recheck · verify`, `report · SARIF`).
   - Updated Golden Fix Recipes empty state with dual-strategy guidance.
   - Fixed stack detection fallback from `Unknown` to `TypeScript`.
   - Synchronized header and footer version to `v1.3.0`.
3. **Strict Timezone & Dependency Invariants:**
   - Standardized Indian Standard Time (IST, UTC+05:30) timestamps across all audit runs, reports, and manifests.
   - Pure Python standard library (zero external dependencies).
