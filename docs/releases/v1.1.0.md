## Summary

TorusGuard v1.1.0 deepens the **Adaptive Security Memory Engine** (`.torusguard/memory/`) with spatial proximity scoring, verified Golden Fix Recipe harvesting, role-tailored context windows, Git pre-commit regression hooks, and sanitized team sharing.

---

## Key Features

1. **File & Rule Proximity Scoring Engine:**
   - Multi-dimensional affinity scoring matches memory cards to the active file being edited (exact file match $\ge 90$, directory match $40-80$, extension match $10-30$).
   - Delivers targeted security advice without cluttering AI context.
2. **Golden Fix Recipe Distillation:**
   - Automatically captures verified Before/After unified diffs from `/torusguard apply`.
   - Strictly bounded by the Ponytail Protocol ($\le 35$ additions, $\le 25$ deletions).
   - Validated against formal JSON schema (`.torusguard/schemas/golden-recipe.schema.json`).
3. **Role-Tailored Context Windows:**
   - Generates specialized memory perspectives for Auditor, Remediator, and Reviewer roles (`--role auditor|remediator|reviewer`).
   - Ensures strict compliance with the 2,000 token prompt limit.
4. **Git Pre-Commit Regression Hooks:**
   - `npx torusguard memory hook install` configures `.git/hooks/pre-commit` to run `diff_guard.py` automatically on staged changes.
5. **Sanitized Team Export:**
   - `npx torusguard memory export --sanitized` removes absolute filepaths, local usernames, and host secrets for safe team collaboration.
6. **Git Commit Learning:**
   - `npx torusguard memory learn` scans repository commit history for recurring security fix patterns.
