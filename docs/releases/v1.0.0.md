TorusGuard v1.0.0 marks the **General Availability (GA)** release of the autonomous application security guardrails engine. TorusGuard now remembers past audit findings, verified fix strategies, false-positive suppressions, and architectural patterns within each project, continuously compounding its precision while guaranteeing zero cloud data leakage.

---

## Core Innovation: Adaptive Security Memory Engine

Traditional static analysis security tools are stateless: they scan, report, and forget. TorusGuard v1.0.0 transforms this model by introducing an intelligent memory loop directly in the user's workspace under `.torusguard/memory/`.

### 4-Tier Memory Architecture

1. **Append-Only Event Ledger (`memory/events/`):**
   Logs chronological security lifecycle events across 6 canonical types (`audit_finding`, `fix_applied`, `fix_verified`, `false_positive`, `pattern_learned`, `stack_changed`) with AST code snippet hashes and relative path tracking.
2. **Distilled Pattern Store (`memory/patterns.json`):**
   Synthesizes raw events into deduplicated, actionable patterns (`recurring_fix`, `common_vulnerability`, `false_positive_class`, `regression_watch`, `security_idiom`) with automated multi-file confidence amplification.
3. **Pre-Computed Context Window (`memory/context.json`):**
   Compiles distilled intelligence into structured JSON cards with strict token budget enforcement ($\le 2,000$ tokens) for instant injection into LLM prompts without token waste or hallucinations.
4. **Project Security Profile (`memory/profile.json`):**
   Captures the project's security DNA — detected technology stack, fix velocity, total events, and top recurring vulnerability categories.

### Intelligent Governance Protocols

- **Confidence Amplification:** When a remediation strategy (e.g., adding `.filter(tenant=user.tenant)`) is repeatedly applied and verified across multiple files, pattern confidence is automatically boosted up to 98%.
- **90-Day TTL Decay:** Historical patterns unconfirmed for 90 days gradually decay in confidence via `memory/decay.json`, ensuring agents never serve stale architectural advice.
- **Event Compaction:** Raw events older than 30 days are automatically condensed into `compacted_archive.json`, eliminating filesystem inode bloat while preserving historical audit telemetry.
- **Export & Import:** Users can explicitly bundle and share memory with team members (`npx torusguard memory export --path ./team-memory.json`), retaining relative path relationships.

---

## Pipeline Integration

- **Memory-Augmented Finding Scorer (`finding_scorer.py`):**
  Adjusts confidence scores based on memory context: +15 points for Regression Watch alerts, +10 points for confirmed recurring patterns, and -30 points for suppressed false positives.
- **Content-Aware Diff Line Scanner (`diff_guard.py`):**
  Integrates `TG-DIFF-004` regression detection: diffs touching files under active Regression Watch are blocked before patch application.
- **Run Lifecycle Manager (`run_manager.py`):**
  Automatically syncs completed run findings into the memory event stream.
- **Autonomous Scaffolding (`bootstrap.py`):**
  Creates the `.torusguard/memory/` layout during `init` and guarantees `.gitignore` isolation.

---

## Privacy & Local-First Invariants

- **Isolated by Default:** The memory directory contains its own `.gitignore` containing `*` (belt-and-suspenders protection).
- **Git Shielded:** Target project `.gitignore` automatically excludes `.torusguard/memory/`.
- **Zero NPM Leakage:** Memory files are strictly excluded from npm publication tarballs.
- **Zero Cloud Dependencies:** Pure Python standard library implementation (`json`, `pathlib`, `datetime`, `uuid`, `hashlib`), zero external network calls, zero subprocesses.

## CLI Commands

```bash
# View workspace security posture and memory metrics
npx torusguard status

# Display memory engine statistics and token usage
npx torusguard memory

# Inspect pre-computed JSON cards for AI agent prompt injection
npx torusguard memory context

# Suppress false positives
npx torusguard memory fp --rule TG-INPUT-002 --reason "Test fixture sink"

# Apply TTL decay to aged patterns
npx torusguard memory decay --ttl 90

# Export memory bundle for team sharing
npx torusguard memory export --path ./shared-memory.json

# Import team memory bundle
npx torusguard memory import --path ./shared-memory.json

# Compact historical events older than 30 days
npx torusguard memory compact
```
