## Wave 1: Full 74-Rule AST Security Catalog Coverage

In prior versions, `audit_runner.py` executed a subset of rules while the complete catalog was defined in specification manifests. With v1.3.5, the core static scanner natively executes detection logic for all **74 rules across all 18 families**:

| Family Code | Domain | Rules Active | Key Invariants Enforced |
| :--- | :--- | :---: | :--- |
| **`TG-SEC`** | Core Secrets & API Keys | 7 | Zero hardcoded API secrets, private certificates, or JWT keys |
| **`TG-AUTH`** | Authentication Integrity | 8 | Constant-time comparisons, password hashing, algorithm verification |
| **`TG-DB`** | Database Isolation & SQLi | 4 | Parameterized SQL queries and tenant partition scoping |
| **`TG-INPUT`** | Input Sanitization | 6 | Safe path sanitization, command escaping, DOM textContent |
| **`TG-RATE`** | Resource Protection | 3 | Rate-limiting middleware on auth endpoints, body limits |
| **`TG-AGENT`** | AI Agent & LLM Defense | 4 | Structural user prompt isolation, delimiter wrapping, schema validation |
| **`TG-SSRF`** | Server-Side Request Forgery | 4 | Hostname whitelisting, private IP range blocking (`169.254.169.254`) |
| **`TG-WEBHOOK`** | Inbound Webhooks | 4 | Cryptographic HMAC-SHA256 verification and replay prevention |
| **`TG-WS`** | WebSocket Security | 4 | Origin verification, handshake auth, frame size limits |
| **`TG-CSRF`** | Cross-Site Request Forgery | 2 | SameSite cookie attributes and anti-CSRF token verification |
| **`TG-GQL`** | GraphQL Safety | 4 | Query depth limiting, production introspection suppression |
| **`TG-SUPPLY`** | Supply Chain Health | 6 | Lockfile integrity, known CVE audits, build script security |
| **`TG-BIZ`** | Business Logic Limits | 4 | Negative amount validation, transaction locks, discount bounds |
| **`TG-CACHE`** | Cache Poisoning & Timing | 3 | Cache-control headers on sensitive data, unkeyed header checks |
| **`TG-CLIENT`** | Client Secrets Leakage | 2 | Zero private environment variables in browser bundles |
| **`TG-PLATFORM`** | Server Hardening | 4 | Helmet security headers, debug mode suppression, cookie secure flags |
| **`TG-DIFF`** | Bypass & Churn Bounds | 3 | Block `# nosec`, `InsecureSkipVerify`, and verify Ponytail diff budgets |
| **`TG-EDGE`** | Edge & Serverless Limits | 2 | Subrequest fan-out limits and execution timeouts |

### High-Precision Scanner Refinements
- **`TG-SSRF-002`**: Targeted active network call sinks (`fetch`, `axios`, `requests.get`) to eliminate false positives on benign object properties like `req.url` or `config.url`.
- **`TG-SSRF-004`**: Eliminated catastrophic backtracking in lookahead regular expressions evaluating AWS and cloud metadata IP addresses.
- **`TG-PLATFORM-002`**: Implemented whole-file AST checks for `helmet()` and security headers middleware, preventing false positive alerts on Express route declarations.
- **False-Positive Exemptions**: Test payloads (`tests/fixtures/payload/`), internal tool scripts (`.torusguard/scripts/`), and markdown docs are automatically shielded from detection noise.

## Wave 3: Expanded Ponytail Remediation Engine

TorusGuard strictly enforces the **Ponytail Protocol** ($\le 35$ additions, $\le 25$ deletions per patch bundle) to prevent AI agents from hallucinating or rewriting functional codebases. In v1.3.5, the remediation engine includes 19 automated patch templates:

1. **SQL Parameterization:** Replaces string-concatenated queries with parameter arrays.
2. **Path Traversal Shield:** Sanitizes file operations using `path.basename` / `os.path.basename`.
3. **CORS Origin Constraining:** Replaces permissive `*` wildcards with environment-controlled origins.
4. **Cookie Security Flags:** Injects `httpOnly: true, secure: true, sameSite: 'lax'`.
5. **TLS Verification Restoration:** Replaces `verify=False` and `InsecureSkipVerify: true` with strict TLS checks.
6. **Multi-Tenant Query Isolation:** Scopes database lookups with `where: { tenantId }`.
7. **Auth Rate Limiting:** Mounts `express-rate-limit` middleware on login and password reset routes.
8. **AI Prompt Injection Shield:** Wraps untrusted user input with XML delimiters and prevents role overriding.
9. **Password Hashing Modernization:** Upgrades legacy `md5`/`sha1` hashing to `sha256` or `bcrypt`.
10. **JWT Algorithm Pinning:** Enforces explicit algorithms array `algorithms: ['HS256']`.
11. **Untrusted Role Header Stripping:** Rejects unauthenticated `X-User-Role` client headers.
12. **Outbound Request Timeouts:** Adds mandatory timeout bounds to `fetch()` and `axios` calls.
13. **Debug Mode Suppression:** Enforces `debug = False` in production configurations.
14. **DOM textContent Safe Reset:** Upgrades `.innerHTML = ''` to safe `.textContent = ''`.
15. **Helmet Security Headers:** Mounts baseline HTTP security headers on HTTP servers.
16. **Timing Attack Protection:** Replaces string equality with `crypto.timingSafeEqual`.
17. **Webhook HMAC Signature Verification:** Adds crypto signature check before body parsing.
18. **GraphQL Introspection Guard:** Disables introspection and schema downloads in production.
19. **WebSocket Origin Validation:** Asserts origin whitelist in connection handshakes.
