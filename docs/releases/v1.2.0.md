## Summary

TorusGuard v1.2.0 delivers **Option B Real-World Usability & Adoption**, closing the gap between security scanning and developer day-to-day workflow. This release introduces two primary capabilities:

1. **AI IDE Rules Auto-Sync Engine:** Automatically extracts active project security invariants, verified Golden Fix Recipes, and active regression watches from `.torusguard/memory/` and compiles them into prompt-optimized rule files for Cursor, Claude Code, Antigravity, and Windsurf — without exceeding a strict $\le 400$ token budget.
2. **Visual Single-File HTML Posture Report:** A zero-external-CDN, fully self-contained, dark-mode visual dashboard featuring an animated SVG circular posture score gauge, an interactive 7-stage closed-loop governance pipeline radar, a golden recipes visual diff viewer, and regression tracking.

## Wave 1: AI IDE Rules Auto-Sync Engine

Traditional security scanners output reports that developers read once and forget. TorusGuard v1.2.0 actively injects verified security constraints directly into the developer's AI coding assistant context.

### Features
- **Multi-IDE Compatibility:**
  - Cursor: `.cursorrules`
  - Claude Code: `CLAUDE.md`
  - Antigravity: `.agent/rules/torusguard.md`
  - Windsurf: `.windsurfrules`
- **Non-Destructive Demarcation:**
  Uses explicit comment boundaries:
  ```markdown
  <!-- TORUSGUARD-SECURITY-GUARDRAILS:START -->
  ... generated invariants, golden recipes, and regression watches ...
  <!-- TORUSGUARD-SECURITY-GUARDRAILS:END -->
  ```
  Pre-existing developer instructions, coding style preferences, and indentation rules outside the markers are 100% preserved.
- **Strict Token Overhead Ceiling ($\le 400$ tokens):**
  Typically consumes only ~180–270 tokens, providing maximum protection without degrading LLM context performance or blowing prompt budgets.
- **CLI Command:**
  ```bash
  npx torusguard rules sync
  npx torusguard rules sync --format cursor
  npx torusguard rules sync --format claude
  npx torusguard rules sync --format agent
  npx torusguard rules sync --format windsurf
  ```

## Wave 2: Visual Single-File HTML Posture Report

A modern, offline-ready security dashboard generated directly to `.torusguard/runs/report-latest.html` for executive reporting, team audits, and CI/CD artifacts.

### Features
- **100% Self-Contained & Air-Gapped:**
  Zero external fonts, zero CDN links, zero remote scripts. Completely compliant with corporate firewalls and restricted air-gapped CI environments.
- **Dynamic Security Posture Score (0–100):**
  Calculated from verified fix velocity, regression alerts, and active golden recipes, rendered using an animated SVG circular gauge.
- **7-Stage Canonical Pipeline Radar:**
  Visualizes the full closed-loop governance flow:
  `1. Scan (/audit) → 2. Score (0-100) → 3. Harden (/harden) → 4. Authorize (Human Gate) → 5. Apply (.bak Snapshot) → 6. Recheck (Differential) → 7. Report (SARIF v2.1.0)`
- **Interactive Golden Recipes Catalog:**
  Displays verified remediation snippets with colored unified diffs and Ponytail bound metrics (+additions / -deletions).
- **Regression Watches & False Positive Suppressions Table:**
  Provides instant visibility into active risk hotspots and cataloged exceptions.
- **CLI Command:**
  ```bash
  npx torusguard report --html
  npx torusguard report --html --out ./security-dashboard.html
  ```
