## Executive Summary

TorusGuard v2.1.3 delivers essential distribution and initialization refinements focused on developer experience, zero-clutter workspace scaffolding, terminal UI visual alignment, and comprehensive multi-track usage documentation:

1. **Strictly Self-Contained Workspace Initialization (`.torusguard/` only):**
   - Eliminated the automatic generation of extraneous `.agent/` and `.agents/` directories.
   - Running `npx torusguard init` now scaffolds exclusively into `.torusguard/` alongside standard root files (`AGENTS.md`).
2. **Terminal UI Visual Alignment Fix:**
   - Corrected card header and body width calculation across Windows Terminal, PowerShell, and Unix shells.
   - Dynamic calculation of emoji display widths (`🛡️`, `✅`) ensuring mathematical 75-column alignment across every line and border.
3. **Comprehensive Multi-Option Usage Documentation:**
   - Added dedicated user guides for **Option 1: npm & npx**, **Option 2: Build from Source**, and **Option 3: Go Install**.
   - Clear explanations of `node_modules` local binary execution via `npx` and `package.json` scripts.
4. **Dynamic Package Version Synchronization:**
   - Synchronized all distribution entrypoints to `v2.1.3`, eliminating legacy hardcoded version strings.

## What's New in v2.1.3

### 1. Clean Initialization (`.torusguard/` only)
Previously, `torusguard init` unpacked IDE bridge directories (`.agent/`, `.agents/`) unconditionally. In v2.1.3, TorusGuard maintains strict directory hygiene:
- Only `.torusguard/` is scaffolded.
- External IDE bridge files (for Cursor, Claude Code, Windsurf, Copilot) are only touched if their respective configuration folders already exist in the target project.
- Slash commands and skills remain completely self-contained in `.torusguard/workflows/` and `.torusguard/skills/`.

### 2. 75-Column Terminal Card Alignment
Terminal box headers and asset unpacking cards have been updated:
- Dynamic whitespace calculation prevents right border shifts when Unicode emojis like `🛡️` or variation selectors are rendered.
- Full parity across `bin/torusguard.js`, `skills/torusguard/bootstrap.py`, and `internal/termui`.

### 3. Dedicated Guides for All 3 Installation Tracks
- **[Option 1: npm & npx Guide](../usage/option-1-npm.md)**: Explains direct `npx` zero-install, global `npm i -g`, and local project installs with `node_modules/.bin` and npm script recipes.
- **[Option 2: Build from Source Guide](../usage/option-2-source.md)**: Details Git cloning, Go compiling, test execution, and contributor workflows.
- **[Option 3: Go Install Guide](../usage/option-3-go-install.md)**: Fast single-binary installation into `$GOPATH/bin` with zero Node.js/Python dependencies.

## Upgrade Instructions

### NPM / NPX Users
```bash
# Direct zero-install (always pulls latest)
npx torusguard@latest init

# Or upgrade global install
npm install -g torusguard@latest
```

### Go Users
```bash
go install github.com/githubmofo/TorusGuard/cmd/torusguard@latest
```
