# TorusGuard v0.2.0 — Structured Audit Framework

**Release date:** 2026-08-18

## Summary

TorusGuard v0.2.0 transforms the project from a basic skill collection into a structured audit-and-remediation framework with 25 stable rule IDs, standardized templates, framework guides, and reference examples.

## Highlights

- **25 documented rules** with severity, detection, remediation, and verification
- **5 commands:** `init`, `audit`, `harden`, `check`, `verify`
- **6 templates** for security context, threat modeling, audits, pre-flight, endpoints, and exceptions
- **5 framework guides:** React/Vite, Next.js, Express, Supabase, Firebase
- **Vulnerable + hardened examples** mapping every rule to concrete code

## Install

```bash
npx skills add https://github.com/githubmofo/TorusGuard --skill "torusguard"
```

## Breaking changes

- Check area names updated: use `database` and `client` (not `frontend-db` / `client-exposure`)
- npm validation scripts removed — TorusGuard is documentation-driven, not an npm package
- Example apps moved to `examples/vulnerable-react-express/` and `examples/hardened-react-express/`

## Upgrade from v0.1.0

1. Re-install or pull latest `skills/torusguard/`
2. Run `/torusguard init` to refresh project `SECURITY.md`
3. Run `/torusguard audit` for rule-ID-based findings
4. Use `/torusguard verify` before deployment

## Known limitations

- Rules detect patterns — manual review still required for RLS, Firebase rules, and business logic
- No CLI detector in this release (planned v0.3.0)
- Example apps are documentation references, not production starters
