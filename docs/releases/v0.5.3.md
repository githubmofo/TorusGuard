## 🎯 Summary

TorusGuard v0.5.3 deepens practical security coverage across real-world Python web application patterns (Django, DRF, FastAPI, Flask, and SQLAlchemy).

Under the theme *“Deeper Python security coverage with framework-native guidance,”* v0.5.3 adds 4 new canonical rules, provides concrete Before/After framework remediations, and extends the validation engine to 62 automated tests with a 100% pass rate.

---

## 🚀 Key Highlights & Enhancements

### 1. 🛡️ 4 New Canonical Security Rules (64 Total)
- **`TG-AUTH-008` (Untrusted Role/Tenant Header Injection):** Detects insecure reliance on client-controlled HTTP headers (`X-User-Role`, `X-Tenant-ID`) for authorization.
- **`TG-INPUT-005` (Unsafe Template Rendering & Disabled Escaping):** Detects `mark_safe()` on user inputs in Django, `| safe` in Jinja2, and SSTI via `render_template_string()` in Flask.
- **`TG-INPUT-006` (Path Traversal & Unsafe Upload Storage):** Detects unsafe `os.path.join(UPLOAD_DIR, filename)` patterns and enforces UUID-prefixed storage with extension whitelisting.
- **`TG-DB-004` (Missing Tenant Query Isolation):** Enforces tenant query filtering (`tenant_id == current_user.tenant_id`) across multi-tenant ORM lookups.

### 2. 🐍 Framework-Native Remediations
- **FastAPI:** Role extraction via `Depends(get_current_user)` from signed JWTs; upload extension whitelisting and UUID storage.
- **Flask:** Template context variable autoescaping; `secure_filename()` with UUID prefixing.
- **Django / DRF:** Safe HTML formatting with `format_html()`; ViewSet tenant scoping in `get_queryset()`.
- **SQLAlchemy:** Parameterized `text(:param)` bindings and scoped tenant filters.

### 3. 🧪 Validation Engine Expansion
- Added 3 new paired differential fixtures in `harness/engine/fixture_manager.py`.
- Automated test suite expanded to **62 passed checks with 0 failures**.
