## Summary

TorusGuard v0.9.5 delivers a comprehensive terminal UX overhaul, resolves the Socket.dev security alert that appeared during `npx skills add` installation, and fixes the GitHub Packages banner rendering issue.

---

## What's Fixed

### Socket.dev `gptAnomaly` Alert Resolution
The "Socket: 1 alert" that appeared during `npx skills add` installation was triggered by Socket.dev's automated heuristic scanner detecting `subprocess.run()` calls inside `bootstrap.py`. This release **eliminates all subprocess usage** from the init/scaffold flow. Stack detection is now deferred to the first `/torusguard-audit` execution, keeping the installation path clean and alert-free.

### GitHub Packages Banner Rendering
The previous tarball (v0.9.4) was published with a stale README containing relative image paths. Publishing v0.9.5 pushes the corrected README (using `raw.githubusercontent.com` absolute URLs) to all registries.

---

## What's Changed

### Premium Terminal UI Overhaul
The entire `npx torusguard init` flow now renders with box-drawn ANSI UI cards:

- **Branded Header Card:** TorusGuard name, version, and tagline in a styled box.
- **Step 1/3 — Unpacking Assets:** Structured breakdown of what was installed (71 rules, 8 schemas, 5 agents, 11 commands).
- **Step 2/3 — Security Profile & Coverage:** Displays all 11 rule families (TG-SEC, TG-DB, TG-INPUT, TG-AUTH, etc.), supported stacks (Python & Node.js frameworks), and deferred stack detection notice.
- **Step 3/3 — AI IDE Registration:** Shows which IDE integrations were registered.
- **Success Card:** Double-border card with next steps (AI Chat, Terminal, CI/CD) and documentation links.

### Step 2 Redesigned
Previously, Step 2 ran `stack_detect.py` via subprocess during init. For new/empty projects this produced useless `Language: Unknown, Framework: None, Data Layer: None`. This release replaces it with a **static Security Profile & Coverage card** showing immediately useful information: rule families, framework coverage, and protocol bounds.

### Enhanced CLI Help & Status
- `npx torusguard help` now shows a full box-drawn command table with options and AI chat slash command documentation.
- `npx torusguard status` now displays rule family breakdown, stack detection status (detected vs pending), and governance telemetry in structured card layout.
