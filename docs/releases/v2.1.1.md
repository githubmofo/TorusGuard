## Detailed Feature Breakdown

### 1. Taint Analysis Engine (`core/taint.py`, `core/taint_rules.py`, `core/taint_graph.py`)
- Tracks untrusted inputs (sources: `request.args`, `req.query`, `params`, `os.environ`, `body`) across intermediate variable assignments to critical security execution sinks (`eval`, `subprocess`, `db.query`, `fs.readFile`, `res.redirect`).
- Recognizes sanitizers (`int()`, `escape()`, `sanitize()`, `DOMPurify.sanitize`, `encodeURIComponent`) to eliminate false positives.
- Constructs directed acyclic taint graphs capturing propagation steps, path depth, and line-level coordinates.

### 2. Polyglot Tree-Sitter Parser & AST Walker (`core/parser.py`, `core/ast_walker.py`, `core/symbol_table.py`)
- Standardizes CST and AST node traversal across Python, TypeScript, JavaScript, and Go.
- Maintains lexical scopes and symbol tables tracking identifiers, function definitions, parameters, and variable assignments.

### 3. Cross-File Interprocedural Dataflow (`core/cross_file_taint.py`, `core/call_graph.py`, `core/import_resolver.py`)
- Resolves cross-file imports (relative paths, package paths, index barrel exports).
- Connects callers and callees into a project-wide call graph, allowing taint flow to propagate across module boundaries.

### 4. 88 Canonical Rules Across 22 Architectural Families
- Expanded the `TG-INPUT` family from 6 to 8 rules:
  - `TG-INPUT-007`: Unvalidated URL Redirects / Open Redirection (`rules/TG-INPUT-007-unvalidated-redirect.md`).
  - `TG-INPUT-008`: Insecure Deserialization / Object Injection (`rules/TG-INPUT-008-insecure-deserialization.md`).
- Loaded and validated via `core/rules_registry.py` and categorized across 22 root-cause clusters in `core/clustering.py`.

### 5. 7-Signal Calibrated Confidence Scorer (`core/confidence.py`, `.torusguard/scripts/finding_scorer.py`)
- Calibrates 0–100 confidence bands using 7 weighted empirical signals:
  1. Rule severity baseline (Critical=90, High=75, Medium=50, Low=25, Informational=10)
  2. Taint path confirmation (+15)
  3. Taint depth decay
  4. Sanitizer presence suppression (-35)
  5. Framework context match (+5)
  6. Multi-line evidence quality (+5)
  7. Test/Mock fixture noise suppression (-30) and documentation suppression (-25)
  8. Persistent memory boost/suppression (-30 to +20)

### 6. Incremental Hash Cache & Parallel Scanning (`core/incremental.py`, `core/parallel.py`, `core/watcher.py`)
- Persists SHA-256 and modification time hashes at `.torusguard/cache/audit_cache.json` to skip unchanged files.
- Distributes directory chunk auditing across CPU cores using a process worker pool.
- Includes file-system watcher with 300ms debounce for continuous background monitoring.

### 7. Master 7-Stage Pipeline (`torusguard full`)
- Coordinates the complete closed-loop security governance lifecycle:
  - Stage 0: `init` (Stack discovery & rule profiling)
  - Stage 1: `authorize` (Cryptographic target scope validation)
  - Stage 2: `audit` (Polyglot AST & multi-modal vision scan)
  - Stage 3: `verify` (Finding confidence calibration & line fingerprinting)
  - Stage 7: `report` (Living ledger synchronization, SARIF v2.1.0 & HTML export)

### 8. Stream-Isolated MCP Server & Unseen Repositories Validation
- Redirected stdout to stderr inside `RunMCPServer()` in `cmd/torusguard/mcp.go`, ensuring 100% pure JSON-RPC 2.0 stdio compliance.
- Validated against 6 unseen ecosystems (SvelteKit 2 + Bun, FastAPI pgvector RAG, Cloud-Native DevOps Docker & Git Mine, Multi-Modal Vision OCR on PNG/JPG/WebP, Kotlin Ktor + Exposed, and Laravel 11 + Vue 3) with full automated sandboxed cleanup.
