# TorusGuard v0.9.3: Dual-Track Distribution & Public NPM Registry Release

**Release Version:** `v0.9.3`  
**Date:** September 3, 2026  
**Status:** Official Production Release  
**NPM Package:** [`torusguard@0.9.3`](https://www.npmjs.com/package/torusguard)  

---

## 🚀 Overview

TorusGuard v0.9.3 marks the official launch of the **Dual-Track Distribution Architecture** and the publication of `torusguard` to the global **npm registry**.

This release addresses terminal ergonomics, eliminates repeating interactive prompt glitches, streamlines AI skill discovery down to a single canonical package, and enhances CLI visual cards across both Node.js and Python environments.

---

## 🌟 Key Highlights

### 1. Dual-Track Distribution Architecture
- **Track 1 (Universal AI Agent Skill):**
  - Installs via Open Agent Skills standard:
    ```bash
    npx skills add https://github.com/githubmofo/TorusGuard -a universal -y
    ```
  - Zero local disk footprint required; pure in-memory reasoning across all 71 security rules.
  - Single master slash command (`/torusguard`) in AI IDE chat.
- **Track 2 (Production NPM Package):**
  - Published to [npmjs.com/package/torusguard](https://www.npmjs.com/package/torusguard).
  - Scaffold repository via `npx torusguard init` or `npm install -D torusguard`.
  - Creates persistent `.torusguard/` directory with offline Python scripts, schemas, and run logs.
  - Unlocks all 11 individual slash commands (`/torusguard-audit`, `/torusguard-harden`, `/torusguard-apply`, etc.).

### 2. Canonical Root `SKILL.md` (Single-Skill Discovery)
- Added canonical root [`SKILL.md`](../../SKILL.md) so `npx skills add` discovers **exactly 1 skill (`torusguard`)** rather than scanning 13 subdirectories.
- Eliminates multi-skill selection confusion for developers.

### 3. Modern Box-Drawn Terminal UX
- Completely redesigned `bin/torusguard.js` and `skills/torusguard/bootstrap.py` terminal output.
- Replaced plain ASCII text with clean Unicode box-drawing cards, colored status badges, environment discovery summaries, and actionable next steps callouts.
- Reconfigured stdout encoding to UTF-8 (`sys.stdout.reconfigure(encoding="utf-8")`) to prevent Windows console `cp1252` encoding exceptions.

### 4. Cross-Registry Markdown Rendering
- Solved the npmjs.com Mermaid rendering limitation by replacing raw Mermaid code blocks with universal high-fidelity Unicode architectural text diagrams and comprehensive markdown lifecycle tables.
- Guarantees 100% pixel-perfect rendering across npmjs.com, GitHub, GitLab, VS Code previewers, and terminal viewers.

### 5. Automated Verification (11 of 11 Test Suites)
- Full battery of 11 test suites passing 100% of assertions:
  - Dual-track architecture, isolation, and command unlocking.
  - Diff guard line inspector (`diff_guard.py`) and monorepo detector (`monorepo_detector.py`).
  - Cryptographic SHA-256 integrity manifest across 93 workspace files.
  - Runtime validation, safety gates, and 5-agent authority separation.
