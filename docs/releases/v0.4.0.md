# Release v0.4.0 — Python Platform Security

**Date:** 2026-08-21  
**Release Name:** Python Platform Security  
**Tag:** [`v0.4.0`](https://github.com/githubmofo/TorusGuard/releases/tag/v0.4.0)

## 🎯 Summary

TorusGuard v0.4.0 adds deep, tested Python platform security guidance while keeping TorusGuard's universal rule catalog framework-agnostic. This release introduces framework-specific security guides, paired intentionally vulnerable and hardened reference applications, validation reports, real-world review records, and automatic stack detection for Python web applications.

---

## 🚀 Key Highlights & What's New

### 1. 🐍 Framework Security Guides
- **[Django](https://github.com/githubmofo/TorusGuard/blob/main/guides/python/django.md):** Production deployment settings (`DEBUG=False`, `ALLOWED_HOSTS`), `CsrfViewMiddleware`, ORM raw SQL safety, `ModelForm` explicit `fields` whitelisting, and `@never_cache` directives.
- **[Django REST Framework (DRF)](https://github.com/githubmofo/TorusGuard/blob/main/guides/python/django-rest-framework.md):** Default permissions (`IsAuthenticated`), ViewSet queryset scoping (`TG-AUTH-007`), serializer `read_only_fields` (`TG-AUTH-006`), `ScopedRateThrottle`, and pagination limits.
- **[FastAPI](https://github.com/githubmofo/TorusGuard/blob/main/guides/python/fastapi.md):** Pydantic v2 schemas (`extra="forbid"`), dependency-based authentication and role checks, outbound SSRF destination validation, and HMAC-SHA256 webhook signatures.
- **[Flask](https://github.com/githubmofo/TorusGuard/blob/main/guides/python/flask.md):** Application factory configuration, session cookie security (`SESSION_COOKIE_SECURE`, `HTTPONLY`, `SAMESITE`), `Flask-WTF` `CSRFProtect`, and Werkzeug `secure_filename()` upload handling.
- **[SQLAlchemy](https://github.com/githubmofo/TorusGuard/blob/main/guides/python/sqlalchemy.md):** Parameterized `text(:param)` bindings, multi-tenant query scoping, and bulk update dictionary allowlists.
- **[Python Dependencies & CI/CD](https://github.com/githubmofo/TorusGuard/blob/main/guides/python/python-dependencies.md):** Deterministic lockfiles (`poetry.lock`, `uv.lock`), `pip-audit` automated scanning, and pinned GitHub Actions commit SHAs.

### 2. 🧪 Paired Educational Reference Applications (`examples/python/`)
Includes 5 pairs of minimal vulnerable and hardened educational applications (Django, DRF, FastAPI, Flask, SQLAlchemy) with explicit `# Intentionally Vulnerable Example` banners and complete `fixes.md` remediation matrices.

### 3. 🤖 Dynamic Python Stack Detection
The skill definition (`skills/TorusGuard/SKILL.md`) automatically inspects repository files (`manage.py`, `rest_framework`, `FastAPI()`, `Flask(__name__)`, `sqlalchemy`, `requirements.txt`, `pyproject.toml`) and dynamically loads matching reference modules during `/torusguard audit`.

### 4. 📑 Validation Suite & Cross-Platform Parity
- Documented validation reports for Django, DRF, FastAPI, and Flask.
- [Cross-Platform Rule Parity Report](https://github.com/githubmofo/TorusGuard/blob/main/docs/validation/cross-platform-rule-parity.md) demonstrating that universal rule concepts remain stable across Node.js and Python.
- Initial [Real-World Validation Records](https://github.com/githubmofo/TorusGuard/blob/main/docs/validation/real-world/README.md) across maintainer-authorized multi-tenant SaaS and microservice codebases.

## 📦 Installation & Usage

Install TorusGuard into your AI coding tool via the open `skills` CLI:

```bash
npx skills add https://github.com/githubmofo/TorusGuard --skill "torusguard"
```

Interact with your coding assistant using the core commands:
- `/torusguard init` — Establish project security baseline and threat model
- `/torusguard audit` — Non-destructive security scan with Human-First report output
- `/torusguard harden` — Apply least-invasive, framework-idiomatic remediations
- `/torusguard check <area>` — Focus on a specific area (`django`, `drf`, `fastapi`, `flask`, `sqlalchemy`, `auth`, `ssrf`)
- `/torusguard verify` — Production pre-flight checklist

## ⚖️ Technical Boundaries & Integrity

TorusGuard is a security guidance framework for AI coding agents. It:
- Is **not** a complete vulnerability scanner or DAST/SAST binary analyzer.
- Does **not** replace professional penetration testing or manual threat modeling.
- Does **not** guarantee 100% security or provide client-side browser DRM.
- Focuses on providing structured, actionable context to AI agents and developers.
