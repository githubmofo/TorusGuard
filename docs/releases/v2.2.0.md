## Executive Summary

TorusGuard v2.2.0 introduces major architectural enhancements inspired by the gold standards of [sindresorhus/awesome](https://github.com/sindresorhus/awesome) and [codecrafters-io/build-your-own-x](https://github.com/codecrafters-io/build-your-own-x). This release completely eliminates friction points in OCR and CLI command execution, ensuring that terminal commands are as intuitive and effortless as AI chat slash commands.

1. **Hybrid First-Principles OCR Engine (Zero External Dependencies):**
   - Built-in binary stream and chunk parser extracts comments, metadata, and printable text from PNG chunks (`tEXt`/`iTXt`), SVG tags, and byte streams without requiring external C++ libraries.
   - If Tesseract OCR is available, TorusGuard augments detection with deep optical raster recognition.
   - If Tesseract is missing, TorusGuard **never aborts with an error**; it scans via the first-principles extractor and displays clear 1-click install guidance (`winget`, `brew`, `apt`).
   - Automatically traverses and discovers workspace diagrams and images (`TorusGuard.png`, docs/assets) with fuzzy targeting if no file path is specified.
2. **Interactive Terminal Command Center:**
   - Running `torusguard` or `npx torusguard` with zero arguments now opens an interactive visual menu with numbered options (`[1]` to `[10]`) rather than dumping a wall of static help text.
3. **100% Tri-Mode Parity for NPM Distribution:**
   - Fixed the `✖ Unknown command: ocr-scan` error when running via `npx torusguard ocr-scan`.
   - Wired all 25 commands into `bin/torusguard.js` with intelligent native binary delegation and pure Node/Python fallbacks.
4. **"Awesome TorusGuard" Curated Rules Catalog:**
   - Added `docs/awesome-rules.md`, organizing all 88 security invariants across 22 architectural families with severity badges, CWE mappings, Ponytail line bounds, and Golden Fix recipes.

## Upgrade Instructions

### NPM / NPX Users
```bash
# Direct zero-install execution (always pulls latest)
npx torusguard@latest

# Or upgrade global installation
npm install -g torusguard@latest
```

### Go Users
```bash
# Update Go binary to latest
go install github.com/githubmofo/TorusGuard/cmd/torusguard@latest
```
