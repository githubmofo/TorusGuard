# Release v0.3.0 - Advanced Web and API Security

**Date**: 2026-08-19

## Overview
TorusGuard v0.3.0 expands the framework to cover complex, modern API architectures and advanced web vulnerabilities. This release introduces 35 new rules across SSRF, business-logic abuse, mass assignment, CSRF, webhooks, GraphQL, WebSockets, supply chain risks, and cache security.

*Note: TorusGuard is an agent-guidance framework, not a complete automated scanner. Manual review is required for complex logic vulnerabilities.*

## New Features
- **SSRF and Outbound Requests**: Network-boundary and outbound-request review.
- **Business-Logic Abuse**: Sensitive-flow and replay-abuse analysis.
- **Authorization**: Mass-assignment and property-level authorization rules.
- **Cross-Origin**: CSRF and credentialed cross-origin request guidance.
- **Webhooks**: Signature, replay, and idempotency rules.
- **GraphQL**: Security guidance for depth, complexity, batching, and resolver authorization.
- **WebSockets**: Authentication, channel authorization, and message validation rules.
- **Supply Chain**: Dependency and CI/CD supply-chain guidance.
- **Caching**: Cache and sensitive-response protection rules.
- **Advanced Examples**: Added advanced API examples and review templates.

## Validation Status
TorusGuard v0.3.0 has been locally validated against OWASP NodeGoat, an intentionally vulnerable Node.js training application. The validation confirmed useful findings for CSRF configuration, sensitive-response caching, and dependency risk. It also confirmed that SSRF and business-logic rules correctly generate manual-review tasks where static analysis cannot determine application intent. This validation does not represent a complete penetration test and does not prove that every TorusGuard rule works across every framework.

## Command Updates
- Expanded `/torusguard audit` to detect API styles and advanced resource-consumption risks.
- Expanded `/torusguard verify` with advanced API and integration checks.
- Check specific areas with `/torusguard check ssrf`, `/torusguard check business-logic`, etc.

*All v0.2.0 rule IDs have been preserved for backward compatibility.*
