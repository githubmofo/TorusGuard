## Executive Summary

TorusGuard v2.0.0-alpha marks a major evolution in autonomous security governance, transitioning TorusGuard into a polyglot Go single-binary engine paired with Multi-Modal Vision OCR and native Model Context Protocol (MCP) agent tools.

Building upon the 74-rule AST security engine, TorusGuard now delivers **Tri-Mode Operational Parity**:
- **Mode A (Terminal CLI):** Deterministic Go binary scanner and enforcer.
- **Mode B (AI Chat Slash Commands):** Prompt and workflow bridges across Antigravity, Cursor, Claude Code, and Windsurf.
- **Mode C (Native MCP Protocol):** Stdio JSON-RPC 2.0 tool execution and living resource streaming for AI coding assistants.

Additionally, TorusGuard introduces hardware-accelerated **Multi-Modal Vision OCR** via Tesseract v5.4.0, scanning architectural diagrams, mockups, and screenshots for leaked credentials with strict 10MB memory safety bounds.

## Detailed Feature Breakdown

### 1. Multi-Modal Vision OCR (`internal/scanner/ocr.go`)
- **Engine:** Tesseract OCR (v5.4.0) with `--dpi 300` resolution enhancement.
- **Target Assets:** Scans `.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`, and `.tiff` diagrams, database schemas, and UI screenshots.
- **Credential Detection:**
  - `TG-SEC-001`: Stripe / OpenAI API keys (`sk_live_...`, `sk-...`)
  - `TG-SEC-002`: AWS Access Key IDs (`AKIA...`)
  - `TG-SEC-003`: GitHub Personal Access Tokens (`ghp_...`)
  - `TG-SEC-004`: PostgreSQL / MySQL / MongoDB database connection URIs
  - `TG-SEC-005`: RSA, EC, and OPENSSH private key blocks
  - `TG-SEC-006`: High-entropy JSON Web Tokens (JWT)
  - `TG-SEC-007`: Plaintext credential and password assignments
- **OCR Character Substitution Tolerance:** Resilient against OCR misreadings (`l` vs `1`, `|`, `t` vs `i`).
- **DoS Safety Envelope:** Bounded to 10MB file size ceiling to prevent resource exhaustion attacks.

### 2. Native Model Context Protocol (MCP) Server (`cmd/torusguard/mcp.go`)
- **Protocol:** Standard JSON-RPC 2.0 stdio server.
- **Exposed Tools:**
  - `torusguard_audit`: Deep static AST scan + Vision OCR; writes `security_report.md`.
  - `torusguard_ocr_scan`: Dedicated image credential analysis via Tesseract.
  - `torusguard_harden`: Validates remediation diff against Ponytail Protocol bounds.
  - `torusguard_recheck`: Differential re-scan confirming fix closure.
  - `torusguard_status`: Workspace posture and tech stack inspection.
- **Exposed Resources:**
  - `torusguard://security_report`: Real-time streaming of the living markdown security report.
  - `torusguard://rules_catalog`: Comprehensive 74-rule metadata catalog.
- **Context Window Protection:** Built-in 32,000-character truncation ceiling (`maxOutputChars = 32000`) preventing prompt context overflows.
