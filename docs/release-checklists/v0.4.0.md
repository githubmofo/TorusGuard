## 📦 4. CI/CD Workflow Automation Suite

All workflows adhere to strict supply chain security standards (pinned actions with 40-character commit SHAs and minimal permissions):

1. **`python-fixtures.yml`**: Matrix tests across all 10 vulnerable and hardened Python reference apps.
2. **`docs-links.yml`**: Validates Markdown relative link integrity, SKILL.md paths, and documentation structure.
3. **`dependency-review.yml`**: Scans pull requests for known vulnerable dependencies.
4. **`secret-scan.yml`**: Audits repository files and commit history for exposed credentials.
5. **`release-check.yml`**: Runs on release tags to ensure version agreement across README, CHANGELOG, and test suites.
