## 🛡️ 2. Detailed Python Rule Specifications

### 1. `TG-AUTH-008`: Untrusted Role or Tenant Header Injection
- **Risk:** Client-supplied headers (e.g. `X-User-Role`, `X-Tenant-ID`) trusted without gateway signature.
- **FastAPI Fix:** Extract roles via `Depends(get_current_user)` from signed JWT claims.
- **Django/DRF Fix:** Derive organization scope strictly from `request.user.tenant`.

### 2. `TG-INPUT-005`: Unsafe Template Rendering & Disabled Autoescaping
- **Risk:** `mark_safe()` on unsanitized input in Django, `| safe` in Jinja2, or `render_template_string()` in Flask.
- **Flask Fix:** Pass inputs as context variables in `render_template("page.html", var=var)`.
- **Django Fix:** Use `format_html()` for safe HTML wrappers with autoescaped variables.

### 3. `TG-INPUT-006`: Path Traversal & Unsafe Upload Storage
- **Risk:** Using raw `file.filename` in `os.path.join()`, permitting `../../` traversal or arbitrary file writes.
- **Flask Fix:** Sanitize with `secure_filename()` and generate random UUID prefixes.
- **FastAPI Fix:** Validate extensions against an allowlist and store with `uuid4().hex` into a verified target path.

### 4. `TG-DB-004`: Missing Tenant Query Isolation in Multi-Tenant Models
- **Risk:** Lookups by record ID (`Invoice.objects.get(id=id)` or `session.get(Item, id)`) without tenant filters.
- **SQLAlchemy Fix:** Enforce `filter(Item.id == item_id, Item.tenant_id == user.tenant_id)`.
- **DRF Fix:** Scope ViewSet `get_queryset()` to `Model.objects.filter(tenant=self.request.user.tenant)`.
