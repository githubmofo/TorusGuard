## 1. Overview

TorusGuard v0.6.2 establishes a version-aware detection and remediation layer that adapts to modern web frameworks, async paradigms, typed configuration loaders, and cloud container manifests.

## 2. Stack Profiling Matrix

| Framework Family | Key Architectural Indicators | Remediation Adaptation |
|---|---|---|
| **Django 5.x** | `aget()`, `asgiref`, `async def` | Emits async ORM tenant scoping (`await Model.objects.aget(...)`). |
| **FastAPI 0.100+** | `Annotated`, `model_validator`, `pydantic_settings` | Emits type-safe `Annotated[User, Depends()]` dependency injections. |
| **SQLAlchemy 2.0+** | `select()`, `AsyncSession`, `mapped_column` | Uses 2.0 select statement chaining (`select(Model).where(...)`). |
| **Next.js 14+** | `"use server"`, App Router | Wraps Server Action mutations in authenticated session guards. |
| **Containers** | `Dockerfile`, `Containerfile` | Adds non-root user declarations and BuildKit secret mounts. |
| **CI/CD** | `.github/workflows/*.yml` | Adds `permissions: read-all` and pins actions to full commit SHA hashes. |
